# 宇宙MAP オープンワールド再設計書

## 目的

宇宙MAPを「素材量の多い宇宙背景」から、**飛ぶだけで楽しく、戦うとさらに意味が出る3Dアクション空間**へ再設計する。

この設計書は、以下を同時に満たすためのものとする。

- 宇宙らしい広がり
- 立体飛行の気持ちよさ
- ランドマークごとの体験差
- フリーフライトでも迷わない導線
- ドッグファイト/総力戦でも使える戦術地形

## 現状の実プレイ観察

ローカルで宇宙MAPを実際に飛行して確認した結果、主な課題は次の通り。

1. 初期スポーン直後の視界がノイジー
2. 小惑星や小物は多いが、大きな飛行ルートが弱い
3. 巨大構造物が「見た目の塊」で、通り抜け導線が読みにくい
4. ゾーン名はあるが、飛行体験としての差が薄い
5. 外周境界が強く、オープンワールド感を壊している

要するに、**マクロでは目的が弱く、ミクロでは情報が多すぎる**。

## 再設計の原則

### 1. 小物より大構造

- 小惑星100個を増やすより、飛びたくなる巨大構造を1個増やす方が価値が高い
- 近距離で避ける粒より、中距離から進路を選ばせる形を優先する

### 2. 見た目より飛行ルート

巨大構造物は造形先行ではなく、次のどれかの役割を必ず持つ。

- 通り抜ける
- 旋回する
- 遮蔽に使う
- 高低差移動の導線になる
- 目標地点として機能する

### 3. ゾーンごとに遊びを変える

各ゾーンは名前だけでなく、飛行時の判断と操作感を変える。

### 4. 外周より内周を豊かにする

プレイヤーが境界まで飛びたくなる状態ではなく、**中央から各ゾーンへ移るだけで十分面白い**状態を目指す。

## 目標体験

宇宙MAPの理想は、次の流れが自然に起きること。

1. スタート直後に遠景の大ランドマークが見える
2. 「あそこに行ってみよう」が自然に生まれる
3. 近づくと、通過口・リング・残骸峡谷などの立体導線が見える
4. 飛び抜けるだけで小さな達成感がある
5. 戦闘時には同じ構造が遮蔽・回避・追跡に使える

## 空間構成

宇宙MAPを6ゾーンの寄せ集めではなく、**3層+5導線**の立体アリーナとして扱う。

### 高層: Transit Layer

役割:

- 高速移動
- 全体俯瞰
- 次の目的地選択

特徴:

- 小物密度を大きく減らす
- 大リング、長い骨組み、発光航路を置く
- 高速でも視認できる大きさにする

### 中層: Combat Layer

役割:

- ドッグファイト
- ミサイル回避
- 中距離の追跡

特徴:

- 大型遮蔽物を点在
- 進路を切り替えられるアーチ、半壊艦、断面リングを置く
- HUDなしでも「抜けられる」が分かる形を優先

### 低層: Technical Layer

役割:

- 狭所飛行
- 探索
- 高リスク高密度のルート

特徴:

- 採掘コロニー、要塞内部、残骸トンネル
- 通れる幅とぶつかる幅を明確化
- 視界は狭くするが、抜け先は必ず見せる

## ゾーン再定義

### 1. 中央補給ステーション

現状の問題:

- スタート地点としては機能するが、周囲の小物密度に埋もれやすい

再定義:

- 「ハブ」専用にする
- 見通しを最優先
- 半径400mは視界クリアリング
- 最初に見える遠景として、各方面の巨大ランドマークを必ず視認可能にする

やること:

- スポーン周囲の小惑星と細いデブリを大幅削減
- 各ゾーン方向に色の違う発光航路オブジェクトを薄く配置

### 2. 破壊された要塞

目標体験:

- 外から侵入し、内部を抜け、別の破口から脱出する

形状方針:

- 板の集合ではなく「中空の防衛拠点」にする
- 3本以上の貫通ルートを保証
- 上下方向の抜けも1本作る

戦闘的価値:

- ミサイルを切れる
- 大型敵の死角を作れる
- 総力戦で砲台と戦艦が最も活きる拠点にする

### 3. 採掘コロニー

目標体験:

- 狭い坑道と空洞をテンポよく切り替える

形状方針:

- 小惑星の外側に施設を貼るだけでなく、内部空洞を主役にする
- トンネル幅は「通れる」ことが見た目で分かるサイズに統一
- 曲がり角の先に必ず光源や抜け先を置く

戦闘的価値:

- 低速での読み合い
- ロック切り
- 狭所でのエースプレイ

### 4. 宇宙船墓場

目標体験:

- 巨大残骸の峡谷を高速で抜ける

形状方針:

- 3〜4隻を散らすのではなく、2隻の巨大艦体と1隻の破断艦で主導線を作る
- 艦体同士の距離を「高速で抜けたい幅」にする
- 船体内部へ入れる箇所を、出入口が分かるように大きく裂く

戦闘的価値:

- 中高速戦
- 機体操作の気持ちよさ
- 遮蔽を使った追跡戦

### 5. 軌道リング都市

目標体験:

- 宇宙版の環状飛行回廊

形状方針:

- 高すぎる飾りではなく、実際に通りたくなる高度へ降ろす
- リングの一部を完全トンネル、一部を半開放アーチにする
- リング全周を使う必要はなく、気持ちいい区間を優先する

戦闘的価値:

- 高速移動
- 長い旋回
- 追跡ルートの読み合い

### 6. 建造現場

目標体験:

- 骨組みの隙間を抜ける立体スラローム

形状方針:

- 細すぎる格子は削る
- 太いフレームを主役にする
- 斜め方向に連続して抜けられる穴を作る

戦闘的価値:

- 初見殺しではなく、慣れると強いショートカット

## 導線設計

宇宙MAPの本体はゾーン単体ではなく、**ゾーン間の移動体験**である。

以下の5導線を用意する。

### 導線A: ハブ → 要塞

- 最初に覚える低層侵入ルート
- 中距離から大きな破口が見えるようにする

### 導線B: ハブ → 墓場

- 最も爽快な中高速ルート
- 小惑星密度を下げ、残骸峡谷を主役にする

### 導線C: ハブ → 採掘コロニー

- 低層の技巧派ルート
- 洞窟の入口が遠目で視認できる必要がある

### 導線D: 墓場 → リング都市

- 上昇しながら広がるルート
- 宇宙らしい高低差移動を強く感じさせる

### 導線E: リング都市 → 建造現場

- 高層の人工構造ルート
- 高速移動からフレーム回避へ操作感を変える

## 削るべきもの

次は積極的に削る。

- ハブ周辺の細かすぎる小惑星
- 意味のない単独デブリ
- 遠景で読む意味のない白い板
- 飛行導線に寄与しない細い棒
- 近づくと何か分からない中サイズの雑多パーツ

宇宙では、密度は「数」ではなく**進路選択の濃さ**で作る。

## 境界の再設計

現状の `RETURN TO COMBAT AREA` と格子境界は機能上必要でも、没入感を壊しやすい。

改善方針:

- 境界そのものを目立たせるのではなく、中央側を面白くする
- 外周は危険宙域として演出する
- 色付き格子は最終警告時だけ強く出す
- それ以前は粒子ノイズ、機体警告、視界歪みで戻した方が自然

## 実装タスク

### Phase 1: 視界整理

- 中央補給ステーション周辺400mの小物密度を下げる
- 小惑星のサイズ階層を整理する
- 大板・細棒・雑多デブリの削除ルールを作る

完了条件:

- スポーン直後に3方向以上の主要ランドマークが読める

### Phase 2: 主導線の可視化

- ハブから各ゾーンへ向かう進路上の小物を間引く
- 導線A〜Eに対応する大構造を追加/再配置する
- ランドマーク単体ではなく、ランドマーク間ルートを作る

完了条件:

- HUDなしでも「どこへ飛ぶと楽しそうか」が分かる

### Phase 3: ゾーン体験の差別化

- 要塞を貫通拠点に再構成
- 採掘コロニーを内部空洞中心に変更
- 墓場を峡谷型に再配置
- リング都市を飛行高度へ再配置
- 建造現場を太いフレーム中心に変更

完了条件:

- 5ゾーンそれぞれで操作感が変わる

### Phase 4: 戦闘地形化

- ミサイル回避に使える遮蔽を各ゾーンへ明示的に配置
- 敵AIの出現位置をゾーンの特徴に合わせる
- 総力戦の大型目標を、地形が活きる場所へ寄せる

完了条件:

- フリーフライトだけでなく戦闘でも地形を使いたくなる

### Phase 5: 境界演出の自然化

- 格子の出方を弱める
- 外周警告を演出的に置き換える
- 可能なら危険宙域エフェクトへ移行

完了条件:

- 外周に触れた時の違和感が大きく減る

## 評価基準

改善後の宇宙MAPは、次の基準で評価する。

1. スポーン直後に行き先が見えるか
2. 30秒飛んで、自然に通りたくなる構造が複数あるか
3. 各ゾーンで飛び方が変わるか
4. 遮蔽物が戦術的に使えるか
5. 外周に行く前に内側で十分満足できるか

## まとめ

宇宙MAPの次の改善は、装飾追加ではない。

必要なのは、

- **小物を減らす**
- **大構造を主役にする**
- **ゾーン間導線を作る**
- **立体飛行の気持ちよさを先に設計する**

という順番での再設計である。

この設計書を基準に、次の実装では「何を増やすか」より先に、**何を削り、どこに飛ばせるか**で判断する。
