# UI設計ルール

## 原則：UI要素は重ならない

**全てのUI要素（ボタン、表示、パネル）は重ならないこと**

- 情報を別の場所に表示するのではなく、ボタンに直接載せる
- 例: スマホ版のミサイル・フレア残量はボタン内に表示
- レイアウト変更時は必ず重なりがないか確認

## スマホ横画面対応（必須）

### 原則
**全ての選択画面・メニュー画面は、スマホ横画面で1画面に収まること**

### 実装チェックリスト

#### 1. メディアクエリの設定
```css
@media (pointer: coarse) and (orientation: landscape) {
  /* スマホ横画面用のスタイル */
}
```

#### 2. 調整項目
- [ ] `gap` を小さく（10px → 4px）
- [ ] `padding` を小さく（通常の50-60%）
- [ ] フォントサイズを縮小（タイトル: 22px以下、本文: 10px以下）
- [ ] `margin-bottom` を小さく（8px → 4px）
- [ ] アイコンサイズを縮小（24px → 16px）
- [ ] ボタンのパディングを縮小（8px → 4px）

#### 3. スクロール対策
```css
#mode-screen {
  overflow-y: auto;
  max-height: 100vh;
}
```

### テスト方法
1. Chrome DevToolsでモバイルモード
2. デバイス: iPhone SE（小型画面）
3. 向き: 横画面（Landscape）
4. スクロールなしで全要素が見えることを確認

### 新機能追加時の注意
- 選択画面に新しいボタン・オプションを追加する時は、必ず横画面での表示を確認
- 縦に要素が増える場合は、既存要素をさらに縮小してバランスを取る
- 最悪の場合はスクロール可能にするが、基本は1画面表示を目指す
