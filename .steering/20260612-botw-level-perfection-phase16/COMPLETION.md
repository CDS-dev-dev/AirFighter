**実装手法**:
```typescript
// 決定的疑似ランダム関数
function deterministicRandom(seed: number): number {
  const x = Math.sin(seed) * 10000
  return x - Math.floor(x)
}
```

- 同じマップを読み込むたびに**完全に同じ配置**
- リロードしても構造物の位置が変わらない
