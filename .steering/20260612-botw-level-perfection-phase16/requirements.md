### 3. 発見要素の大幅増加（50時間）🔴

#### 目標数

**隠しエリア**: 30個 → **150個**
- Original: 50個
- Tokyo: 50個
- Space: 50個

**コレクティブル**: 75個 → **300個**
- Original: 100個
- Tokyo: 100個
- Space: 100個

**新カテゴリ: 記録（Logs）**: **120個**
- 日記: 40個
- 音声記録: 40個
- 石碑/碑文: 40個

#### 配置の原則

1. **視線誘導**: 遠くから見える→近づくと次が見える
2. **3点配置**: 常に3つの発見要素が視界に
3. **報酬の段階**: Easy(50%) → Medium(30%) → Hard(15%) → Expert(5%)
4. **物語の連鎖**: 複数の要素が1つの物語を語る

```typescript
interface BiomeEffect {
  snow: {
    speedMultiplier: 0.9,      // 10%速度低下（吹雪）
    visibilityReduction: 0.7,  // 視界30%低下
    hazard: 'frostbite',       // 長時間滞在で効果
  },
  jungle: {
    speedMultiplier: 0.85,     // 15%速度低下（密林）
    visibilityReduction: 0.8,  // 視界20%低下
    hazard: 'overgrowth',      // 植生が邪魔
  },
  desert: {
    speedMultiplier: 1.0,      // 速度正常
    visibilityReduction: 0.6,  // 視界40%低下（砂嵐）
    hazard: 'heatwave',        // 熱波
  },
}
```
