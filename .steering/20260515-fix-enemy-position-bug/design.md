# 設計書

## 修正内容

### 1. 戦術目標位置の動的更新
- `tacticUpdateTimer`の更新周期を維持しつつ、目標位置計算時に常にターゲットの現在位置を使用
- 相対位置ベースの計算に変更（絶対座標への変換は計算時に行う）

### 2. 振動防止
- 目標位置への到達判定を追加（距離20m以内で速度を減速）
- 目標位置付近では移動速度を段階的に低下させる

### 3. 高度制限
- 最低高度：15m（地面との接触回避）
- 最高高度：150m（不自然に高い位置を防ぐ）
- ドッグファイト時の高度オフセットを調整

### 4. 移動ロジックの改善
- 目標位置までの距離が一定以下の場合、速度を減速
- 滑らかな高度変化のための補間を追加
