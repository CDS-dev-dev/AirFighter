# MAP革命 - 要求定義

## 背景
現状の問題：
- **オリジナルMAP**: 高低差が中央部のみ。全体の80%は平坦で退屈
- **東京MAP**: 重い（4000棟+2000本の樹木）、地形高低差が見えない、飛行が単調

## 目標

### オリジナルMAP改革：「全域で激しい高低差」
**コンセプト**: どこを飛んでも地形を気にする必要がある

#### 要求
1. **高低差を10倍に増幅**
   - 現在：中央部400m、周辺部50-150m
   - 目標：全域で300-800m級の山岳・峡谷
   
2. **地形特徴を全域に配置**
   - 巨大な山脈（連続する高地）
   - 深い峡谷群（複数の大渓谷）
   - 急峻な崖（垂直に近い地形）
   - 狭い峡谷（ビルの間を縫うような飛行）
   - 岩の塔・尖峰（障害物）
   
3. **飛行で楽しめる要素**
   - 峡谷の間を縫う飛行
   - 山の稜線に沿った飛行
   - 崖の壁面すれすれ飛行
   - 岩塔の間を抜ける飛行

4. **オブジェクト追加**
   - 岩の塔（30-80m）：100本以上
   - 巨岩（10-30m）：300個以上
   - 崖の突起物
   - 峡谷の橋（既存強化）

### NEO東京MAP：「サイバーパンク都市」
**コンセプト**: ブレードランナー的な立体都市

#### 要求
1. **軽量化**
   - 建物数：4000棟 → 1500棟（InstancedMesh使用）
   - 樹木：2000本 → 0本（削除）
   - 目標：現在の50%の負荷
   
2. **立体都市構造**
   - 超高層ビル（500-800m）：50棟
   - メガストラクチャー（巨大建造物）
   - 空中道路（ビル間を繋ぐ橋）：50本
   - 垂直農場（緑の高層建築）
   - ホログラム広告塔
   
3. **地形高低差を視覚化**
   - ビルを地形に沿って配置
   - 台地の縁に超高層ビル
   - 低地に工業エリア
   - 段差を強調する配色
   
4. **サイバーパンク要素**
   - ネオンカラー（青・紫・赤の発光）
   - 暗めの基調（夜の都市）
   - 高密度だが視認性良好
   - 飛行しやすいメガストリート（幅広道路）

## 技術的制約
- フレームレート：30fps以上維持（スマホ）
- InstancedMesh必須（NEO東京）
- LOD導入検討

## 成功基準
1. オリジナルMAP：全域で地形を気にしながら飛行できる
2. NEO東京：軽量で視覚的に圧倒的
3. どちらも現行より飛行が楽しい
