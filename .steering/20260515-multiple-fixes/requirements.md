# 要求内容

## 修正項目

### 1. 操作系の問題（最優先）
- **上下反転時の左右操作が逆**: 背面飛行時に左右コマンドの動く方向が逆になっている
- **水平復帰時の方向異常**: 手を離して水平に戻る際、勝手に変な方向を向き始める
- **視点操作の追加**: 右側のボタン以外の部分を上下左右することで、視点（カメラアングル）も変更できるようにする

### 2. ロックオンシステムの問題
- **ロックオン範囲**: 画角外や遠い敵もロックオン候補になっている
- **修正**: ロックオン範囲内の敵のみをターゲットにする（視界内＋一定距離以内）

### 3. 衝突判定の問題
- **オリジナルマップ**: 山の裏側に行けたり、衝突判定が不完全
- **構造物**: 地形や構造物によって衝突判定がない箇所がある

### 4. オリジナルマップの改善
- **空中物体のサイズ**: 小さいと回避しにくいのに当たり判定があり、UX悪い
- **サイズ変更**: 大きめにして視認性と回避可能性を向上
- **マップ設計**: 立体的な飛行を楽しめるように、しっかり時間をかけて設計

## 優先順位
1. 操作系（左右反転、水平復帰、視点操作）
2. ロックオンシステム
3. 衝突判定
4. オリジナルマップ改善
