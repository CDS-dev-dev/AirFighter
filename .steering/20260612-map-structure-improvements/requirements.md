# Phase 9: MAP構造物デザイン改善

## 実装日
2026-06-12

## バージョン
v5.55.0 → v5.56.0

## 問題点

### 1. Tokyo MAPのビルが高すぎる 🔴
**現状**:
```typescript
超高層ビル: 1700-2400m（中心部）
高層ビル: 1150-1900m（新宿）
中層ビル: 760-1300m（渋谷）
```

**問題**:
- 現実の東京（高さ制限250m程度）と乖離
- プレイヤーの巡航高度（200-500m）より遥かに高い
- 世界観が崩れる

**改善**:
```typescript
超高層ビル: 400-800m（中心部）← 半減以下
高層ビル: 300-500m（新宿）
中層ビル: 200-400m（渋谷）
一般ビル: 100-250m（密集地区）
```

---

### 2. Original MAPの岩柱が小さい 🟡
**現状**:
```typescript
岩柱: 高さ60-130m、半径9-25m
孤立タワー: 高さ115-130m
```

**問題**:
- 巡航高度200mだと簡単に飛び越えられる
- 障害物として機能しない
- 視覚的インパクトが弱い

**改善**:
```typescript
岩柱: 高さ150-300m（2-3倍）、半径15-40m（1.5-2倍）
孤立タワー: 高さ250-350m（2-3倍）
アーチ: 高さ100m（既存62m→1.6倍）
```

---

### 3. 飛行回廊の不明瞭 🟡
**現状**:
- Tokyo: Urban Canyonが定義されているが視覚的に不明瞭
- Original: 峡谷はあるが意図的な飛行ルートになってない

**問題**:
- プレイヤーがどこを飛べばいいか分からない
- 戦術的な意味が薄い

**改善**:
- Tokyo: Urban Canyon沿いのビル高を統一（壁のように）
- Original: 峡谷の深さを強調、ナビゲーションビーコンを峡谷入口に配置

---
