# NEO Tokyo 構造物・形状の全面強化

## 現状の問題（ユーザーフィードバック）

1. **ビルが直方体だけ** → 単調、面白くない
2. **くぐる場所がない** → 立体感が楽しめない
3. **サイバーパンク感が薄い** → 未来都市に見えない

## 設計方針

**「くぐって楽しい、見て楽しい、未来都市」**

### コンセプト
- 飛行ルートに「くぐるポイント」を配置
- ビル形状にバリエーション
- 非現実的な構造（サイバーパンクらしく）

## 実装する構造物

### 1. メガリング（Mega Rings）

**配置**: 3-4個、各地区のランドマーク

| 名前 | 位置 | 直径 | 高度 | 色 |
|---|---|---|---|---|
| Tokyo Station Ring | (0, 0) | 1000m | 400m | 青 |
| Shinjuku Ring | (-2000, 0) | 800m | 600m | シアン |
| Odaiba Ring | (2000, 2000) | 900m | 300m | アクア |

**構造**:
```
TorusGeometry(外径, 内径, 断面セグメント, 周セグメント)
外径 = 直径 / 2
内径 = 40-60m（リングの太さ）
```

**ネオン**:
- リング全体が発光（emissive 1.0）
- 内側に光の流れ（アニメーション風）

### 2. メガアーチ（Mega Arches）

**配置**: 6-8個、ビル間を接続

| タイプ | 配置 | サイズ | 説明 |
|---|---|---|---|
| High Arch | Core地区 | スパン400m, 高さ800m | ビル2棟を結ぶ |
| Mid Arch | Shinjuku | スパン600m, 高さ600m | 広い道路の上 |
| Low Arch | Shibuya | スパン300m, 高さ400m | 密集エリア |

**構造**:
- CylinderGeometry を曲線配置（複数のセグメント）
- または TorusGeometry の一部
- 下をくぐれる

**ネオン**:
- アーチ全体が発光
- 下から見ると光のトンネル

### 3. リングビル（Ring Buildings）

**配置**: 5-6個、Core/Shinjukuに

**構造**:
```typescript
// 外側の壁
CylinderGeometry(外径, 外径, 高さ)
// 内側の壁（くり抜き）
CylinderGeometry(内径, 内径, 高さ) - 削除

実装: 2つのCylinderの差分
または: RingGeometry を押し出し
```

**サイズ**:
- 外径: 200-300m
- 内径: 120-180m（くぐれる）
- 高さ: 1000-1500m

**ネオン**:
- 内側の壁が発光
- くぐると光のトンネル

### 4. 円柱タワー（Cylinder Towers）

**配置**: 10-15個、各地区に散在

**サイズ**:
- 直径: 150-300m
- 高さ: 800-1800m

**バリエーション**:
- 単純な円柱
- 上に行くほど細い（ConeGeometry）
- 下に行くほど細い（逆円錐）

### 5. ピラミッド/逆ピラミッドビル

**配置**: 3-4個、Core/Odaiba

**構造**:
```typescript
// 正ピラミッド
CylinderGeometry(0, 底面半径, 高さ, セグメント数)

// 逆ピラミッド（非現実的）
CylinderGeometry(頂点半径, 0, 高さ, セグメント数)
// 空中に浮いているように見える
```

**サイズ**:
- 底面: 300-500m
- 高さ: 1000-1500m

### 6. ねじれタワー（Twisted Towers）

**配置**: 2-3個、Shibuya/Shinjuku

**構造**:
```typescript
// BoxGeometry を垂直に複数配置
// 各セグメントを少しずつ回転
for (let y = 0; y < height; y += segment_height) {
  rotation.y = (y / height) * Math.PI
}
```

**サイズ**:
- 底面: 200-300m
- 高さ: 1000-1400m
- 回転: 0-90度

### 7. 斜めビル（Tilted Buildings）

**配置**: 3-4個、Shibuya

**構造**:
```typescript
BoxGeometry を傾ける
rotation.z = 15-30度
```

**効果**:
- 視覚的にインパクト
- 非現実的だがサイバーパンクらしい

### 8. 十字/L字ビル（Complex Shapes）

**配置**: 5-6個、各地区

**構造**:
```typescript
// 複数のBoxGeometryを組み合わせ
Group に追加
  ├─ 縦棒 BoxGeometry(w, h, d)
  ├─ 横棒 BoxGeometry(w2, h2, d2)
  └─ 接続部
```

### 9. 浮遊リング構造（Floating Ring Complex）

**配置**: 1個、Odaiba上空

**構造**:
```typescript
// 3つのリングが異なる角度で重なる
Ring 1: 直径 1200m, 水平
Ring 2: 直径 1000m, 30度傾き
Ring 3: 直径 800m, 60度傾き
```

**効果**:
- 飛行ルートが複雑
- 視覚的に未来的

### 10. トンネルビル（Tunnel Buildings）

**配置**: 2-3個、Core地区

**構造**:
```typescript
// 巨大なビルに横穴
BoxGeometry メイン
- CylinderGeometry を横向きで「削除」（穴として表現）
実装: 2つのBoxを配置（上下）＋穴
```

**サイズ**:
- ビル: 500m四方
- トンネル: 直径100-150m

## サイバーパンク演出強化

### ネオン強化
- emissive を明るく戻す: 0.5-1.0
- リング・アーチは常時発光（emissive 1.2-1.5）

### 色彩
- **リング**: 虹色グラデーション or 地区カラー
- **アーチ**: 青→シアン→緑のグラデーション
- **ビル**: 既存の地区カラー維持

### 動的エフェクト（オプション）
- ホログラムの回転
- ネオンの明滅パターン

## 実装順序

### Phase 1: メガリング（優先度：最高）
1. TorusGeometry でリング作成
2. 4箇所に配置
3. ネオン発光

### Phase 2: メガアーチ（優先度：高）
1. Cylinder の曲線配置
2. 5-6箇所
3. ネオン発光

### Phase 3: ビル形状バリエーション（優先度：高）
1. リングビル
2. 円柱タワー
3. ピラミッド
4. ねじれタワー
5. 斜めビル

### Phase 4: 複雑構造（優先度：中）
1. 十字/L字ビル
2. 浮遊リング構造
3. トンネルビル

### Phase 5: 最終調整
1. ネオン強度調整
2. 衝突判定追加
3. パフォーマンス確認

## 期待される結果

- **くぐる楽しさ**: リング・アーチ・トンネルで立体飛行
- **視覚的多様性**: 10種類以上の形状
- **サイバーパンク感**: 派手なネオン、非現実的形状
- **飛びやすさ維持**: 広い空間は維持
