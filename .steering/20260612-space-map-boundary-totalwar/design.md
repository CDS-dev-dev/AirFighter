# 設計書：宇宙MAP境界 & 総力戦モード

## 1. MAP境界システム設計

### 1.1 境界の定義
```typescript
const SPACE_MAP_BOUNDS = {
  minX: -3000, maxX: 3000,  // 6km
  minZ: -3000, maxZ: 3000,  // 6km
  minY: -2400, maxY: 2400   // 4.8km vertical play space
}
```

### 1.2 格子表示
- **構造**: 立方体の6面に200m間隔の格子
- **色**: オレンジ（0xff6600）
- **透明度制御**:
  - 境界から300m以上: opacity = 0（見えない）
  - 100m〜300m: フェードイン（0〜0.7）
  - 100m以内: opacity = 0.7（最大）

### 1.3 境界制限
- **プレイヤー**: 各軸で境界値を超えたら境界値に固定
- **敵**: 同様に境界値で制限
- **理由**: ゲームプレイエリアを明確にし、無限に飛んでいけないようにする

## 2. ゾーン配置の3次元化

### 2.1 問題の分析
配置前のY軸標準偏差比率：8.9%（X軸51%、Z軸40%）
→ 平面的で3D空間を活用していない

### 2.2 解決策
Y軸を-1800〜+2000まで拡張（3800mレンジ）

### 2.3 最終配置
```
central_hub:    (0, 0, 0)
fortress:       (600, -800, -2400)
mining_colony:  (-2300, -1800, -400)
ship_graveyard: (2200, 600, 2000)
orbital_ring:   (-600, 2000, -2200)
construction:   (2000, 1600, -100)
```

**標準偏差比率**: X軸35.5%、Y軸30.3%、Z軸34.2% → ほぼ均等

## 3. 総力戦モード設計

### 3.1 戦艦（Battleship）
**外観**:
- 船体: 400m×60m×80m（BoxGeometry）
- 艦橋: 前方に60m×80m×50m
- 主砲塔: 3基（各直径20-25m）
- エンジン発光: 後方に青い光（PointLight）

**性能**:
- HP: 20
- 攻撃: 主砲3門から高速弾丸（500m/s）
- 射程: 1200m
- 発射間隔: 2.0〜3.0秒
- 配置数: 4隻（各主要ゾーン付近）

**配置座標**:
```
要塞付近:         (800, -600, -2200)
採掘コロニー付近: (-2000, -1600, -200)
船墓場付近:       (2000, 800, 1800)
軌道リング付近:   (-400, 1800, -2000)
```

### 3.2 砲台（Turret）
**外観**:
- 基部: 円柱（直径12-18m、高さ20m）
- 砲塔: 球体（直径15m）
- 砲身: 円柱（直径3m、長さ50m）
- レーダー光: 赤い光（PointLight）

**性能**:
- HP: 5
- 攻撃: 超高速レーザー弾（600m/s）
- 射程: 800m
- 発射間隔: 3.0〜4.5秒
- 砲塔回転: プレイヤー方向に自動追尾
- 配置数: 14基（構造物に付属）

**配置戦略**:
- 要塞: 4基（東西南北+上下）
- 採掘コロニー: 3基（入口周辺）
- 船墓場: 3基（廃船上）
- 軌道リング: 4基（リング周辺）

### 3.3 攻撃パターン
**戦艦**:
1. プレイヤーが1200m以内に接近
2. 3門の主砲から同時発射
3. 高速弾丸（500m/s）で直進
4. 2〜3秒のクールダウン

**砲台**:
1. プレイヤーが800m以内に接近
2. 砲塔がプレイヤー方向に回転
3. 超高速レーザー弾（600m/s）で直進
4. 3〜4.5秒のクールダウン

## 4. 技術的決定事項

### 4.1 削除された機能
- ゲートブースト機能（updateSpaceGates関数、playGateBoostSound関数）
- ゲート構造物（5個のトーラス）
- ゲートベースの方向キュー

### 4.2 追加されたインターフェース
```typescript
interface GroundTarget {
  // ...既存フィールド
  type?: 'ship'|'tank'|'sam'|'bomber'|'heli'|'battleship'|'turret'
  attachedTo?: string  // 砲台専用: どのゾーンに付属
  turretRotation?: number  // 砲台専用: 砲塔回転角度
}
```

### 4.3 新規関数
- `createMapBoundary()`: MAP境界格子を生成
- `updateMapBoundary()`: 距離に応じて透明度を更新
- `createBattleship()`: 戦艦オブジェクトを生成
- `createTurret()`: 砲台オブジェクトを生成
- `spawnSpaceTotalWarEnemies()`: 総力戦モードの敵配置

## 5. パフォーマンス考慮
- MAP境界格子: LineSegmentsで軽量実装
- 戦艦: プリミティブ形状の組み合わせ（GLBなし）
- 砲台: 同上
- 攻撃判定: 既存のenemyBullets配列を再利用
