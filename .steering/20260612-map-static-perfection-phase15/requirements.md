### 5. 密度均一化（120分）🟡

#### 密度グラデーションの実装

```typescript
function getDensityMultiplier(distance: number, mapType: GameMap): number {
  // 中心からの距離に応じた密度倍率
  // 0-2000m: 1.0（100%）
  // 2000-4000m: 0.8（80%）
  // 4000-6000m: 0.6（60%）
  // 6000-8000m: 0.4（40%）
  // 8000+m: 0.2（20%）
  
  if (distance < 2000) return 1.0
  if (distance < 4000) return 0.8
  if (distance < 6000) return 0.6
  if (distance < 8000) return 0.4
  return 0.2
}
```
