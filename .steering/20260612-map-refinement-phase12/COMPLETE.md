### Task 4: Original MAP 地形メリハリ（標高別植生） ✅

#### 樹木配置条件の改善
**変更前**: 標高800m以下に木を配置
```typescript
if (ty > 800 || treeSlope > 6.0 || ...) { i--; continue }
```

**変更後**: 標高別の植生分布
```typescript
// 高地（500m-）: 木を生やさない
if (ty > 500) { i--; continue }

// 中腹（200-500m）: まばらな木（60%スキップ）
if (ty > 200 && Math.random() < 0.6) { i--; continue }

// 低地（0-200m）: 密林（全体の40%が残る）
```

**効果**:
- 高地: 岩肌のみ（山岳感）
- 中腹: まばらな木（標高の変化を感じる）
- 低地: 密林（森林感）

**視覚的変化**: 標高による明確な植生変化、地形のメリハリ向上
